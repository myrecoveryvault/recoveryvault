The Field Rig: Recommended Tool Engine

Zero Vendor Lock-in

This system requires zero proprietary app subscriptions. Everything is built on local plain-text Markdown files that you physically own on your hard drive, mirrored securely across your personal hardware:

Obsidian (Core Engine) Desktop / Mobile

The offline storage, bi-directional linking, and Markdown reader.

Plugin Bundle: The starter `.zip` includes the hidden .obsidian/ folder with pre-configured settings, keybindings, and lightweight community plugins so it behaves like an instrument immediately.
Drive Sync Architecture Multi-Device
  • PC / Mac: Local vault set to Mirror files via Google Drive desktop client for automatic off-site redundancy.
  • Android / Tablet: Pair with DriveSync to keep local phone storage synchronized with Google Drive.
  • iPhone / iPad Alternative: Use the free Remotely Save Obsidian plugin (syncs to Google Drive, S3, or WebDAV) or sync via native iCloud Drive.
ExtendLM Extension Chrome Extension

Browser extension used for high-efficiency source curation. One-click batch intake of exegesis sources, YouTube transcripts (sermons/speaker tapes), and web articles directly into NotebookLM without clipboard clutter.

NotebookLM & Gemini Pro Isolated Query Node

Strictly isolated read-only models. Mount your exported vault folders or telemetry archives to query multi-month patterns, audit moral inventory adherence, and extract objective behavioral data—zero hallucinations.
